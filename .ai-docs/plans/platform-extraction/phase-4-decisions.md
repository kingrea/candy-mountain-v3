## ncj.4.1 Turborepo (done)
- Root scripts: build/test/lint/typecheck run `turbo run`; typecheck uses --concurrency=1 (keep it). lint also runs //#lint:root for root-level files.
- A new package joins the pipeline by declaring package.json scripts: "lint": "eslint .", "test": "vitest run", "typecheck": "tsc --noEmit" (or "nuxt typecheck"), and "build" only if it builds. Turbo skips tasks a package does not declare.
- Build outputs cached only from dist/** and .output/**.
- Tests need NO registration in a root vitest config (it was deleted). A package needs vitest.config.ts via definePackageTestConfig and a "test" script. (Supersedes the ncj.4.2 note about root vitest projects.)
- Invalidation follows package.json dependencies/devDependencies: a package MUST list every workspace package it imports (workspace:*).
- CM_* env vars are automatically in build/test hashes; other env vars affecting output go in turbo.json env lists.
- Root-level files in new root folders need //#lint:root inputs extended in turbo.json.

## ncj.4.20 platform-cli (done)
- apps/cli's commands, supervisor, systemd/unit-file generation, pid and log handling moved as they are to packages/platform-cli, @candy-mountain/platform-cli (private, source export "." -> ./src/index.ts, no build; scripts lint/test/typecheck). It imports only platform-config and platform-sdk root entries; its tests import no app.
- Entry: `runCli(argv: string[], distribution: Distribution, host?: CliHost): Promise<number>` (exit code). Root exports runCli, types Distribution, AppLocation, CliHost, Io.

  - Names derive from product.name via platform-config's dataDirName: command `candy-mountain` (usage text, advice messages), unit `candy-mountain.service`, env file `~/.config/candy-mountain/service.env`. CM_* env vars unchanged. A distribution's bin name in package.json must match that slug.
- Thin bin (apps/cli, still @candy-mountain/cli with bin candy-mountain, tsdown bundles @candy-mountain/*): src/distribution.ts `candyMountain(repoRoot): Distribution` (product CANDY_MOUNTAIN_PRODUCT from platform-sdk; cliEntry apps/cli/dist/index.mjs; daemon apps/daemon/dist/index.mjs cwd apps/daemon; web apps/web/.output/server/index.mjs cwd apps/web; dataDir: env => resolveDataDir(CANDY_MOUNTAIN_PRODUCT, env)); src/index.ts `process.exitCode = await runCli(process.argv.slice(2), candyMountain(REPO_ROOT))`; src/repo-root.ts unchanged. apps/cli/src/product.ts is gone. ncj.4.17: swap the CANDY_MOUNTAIN_PRODUCT import in apps/cli/src/distribution.ts for the candy-mountain product package and add it to apps/cli dependencies.
